# MineGuard Compliance Command

A modular AI-assisted governance and compliance monitoring system for coal-mine operations, built with Python Flask.

## 🎯 Project Overview

MineGuard enables workers and site teams to report safety incidents, operational risks, environmental concerns, and compliance findings. Control-room administrators can classify risk, review evidence, assign accountable teams, and maintain an auditable case lifecycle.

## ✨ Features

### Worker & Site-Team Features:
- **Worker Registration & Login** - Secure authentication with password hashing
- **Incident Reporting** - Capture mine area, evidence, voice notes, and observations
- **AI Risk Classification** - Detect safety, ventilation, operations, environment, and welfare signals
- **Case Tracking** - Follow status updates and accountable control-area responses
- **Evidence Trail** - Preserve photo, GPS, authenticity, and AI analysis metadata

### Control-Room Features:
- **Governance Dashboard** - Monitor total, pending, active, resolved, and escalated cases
- **AI-Assisted Routing** - Route cases to safety, operations, ventilation, maintenance, environment, or regulatory owners
- **Multimodal Review** - Combine text, image, voice, sentiment, and location evidence
- **Auditability** - Track responses, assignments, escalation reasons, and case history

## 🛠️ Technology Stack
- **Backend**: Python 3.x, Flask (Blueprints for modularity)
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **Security**: Werkzeug password hashing

## 🚀 Installation & Setup

1. **Install required packages**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the application**:
   ```bash
   python app.py
   ```

3. **Open browser**:
   `http://127.0.0.1:5000`
